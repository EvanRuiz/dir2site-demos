# dir2site-demos

Example sites generated with [Dir2Site](https://github.com/EvanRuiz/dir2site).

Dir2Site is an open-source desktop app that turns any local folder into a polished static website — photo galleries, PDFs, Markdown articles, and more. Your filesystem is your CMS; everything is stored as plain YAML files alongside your content, trackable in git.

## Demo: Famous Physicists

* Preview Generated Site: [Famous Physicists Demo](https://evanruiz.github.io/dir2site-demos/physicists/_site/)
* Browse source project directory: [Project Directory](https://github.com/EvanRuiz/dir2site-demos/tree/main/physicists)

> Note: Demo content (images, biography, papers) was generated or collected by AI for testing purposes. Any inaccuracies are unintentional — please open an issue to report them.

## About this repo

Each folder here is a self-contained demo site produced by Dir2Site. Browse the source folders to see how content and configuration files are structured, or open the generated `_site/` subfolder to view the HTML output directly.

## Getting Dir2Site

Download or build Dir2Site from the main repository:
**[github.com/EvanRuiz/dir2site](https://github.com/EvanRuiz/dir2site)**

Full documentation, feature list, and build instructions are there.

## Running a demo locally

1. Clone this repo
2. Open Dir2Site and select any demo folder as your **Site Project Folder**
3. Click **▶ Start** to launch the built-in preview server and open it in your browser
